# MSc_Thesis_Misinfo

This repository contains all code pertaining to the Master's thesis **"Explainable Facts: Automatic and Explainable Fact-Checking of Misinformation via Language Models"**.

All data used for this thesis were obtained from Yang et al. (2022), available from [their repository](https://github.com/Nicozwy/CofCED).

To reproduce the same environment, use the `pyproject.toml` file with `uv`, or `pip` by extracting the packages from the `.toml` file.
